This version saves to this browser's local storage. Clearing browser data may erase it. Export backups regularly and keep them somewhere safe. Data is not cloud-synced or encrypted by DAYSTAR in this version.

Firebase setup and configuration

Security: enable Firestore rules from the included file before using cloud sync. Never share private service-account keys; this app only uses the public web-app config.

Privacy & reset

Local records stay in this browser unless you explicitly configure and connect cloud sync. Export a backup regularly. Deleting local data does not automatically delete your cloud copy.
